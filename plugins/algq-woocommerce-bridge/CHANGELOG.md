# Changelog

## 2.0.0 — 2026-08-17

- Replaced append-only access logging with idempotent entitlement records.
- Added refund, cancellation, and failure revocation.
- Added WooCommerce Subscriptions status integration.
- Added expiration controls and product-level access settings.
- Added HPOS compatibility declaration and WooCommerce API-based order reads.
- Added legacy access-log migration.
- Added entitlement diagnostics and platform audit/event hooks.
- Raised requirements to WordPress 6.8 and PHP 8.2.
- Added valid WPBakery page generation and conservative uninstall handling.

## 1.0.0

- Initial bridge and dashboard release.

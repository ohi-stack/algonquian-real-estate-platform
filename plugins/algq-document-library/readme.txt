Secure institutional document records, version controls, access requests, protected downloads, and document-package assembly for the Algonquian Real Estate platform.

== Description ==

Algonquian Document Library centralizes entity, lender, acquisition, financial-control, risk, compliance, and property-management document records. Version 2.0.0 adds private storage, protected delivery, durable access requests, file hashes, document governance metadata, package assembly, and platform integration points.

== Installation ==

1. Upload the plugin directory to `/wp-content/plugins/`.
2. Activate Algonquian Document Library.
3. Confirm private-storage health in Document Library > Overview.
4. Assign capabilities to authorized platform roles.
5. Add authoritative document records and protected files.
6. Test access requests and downloads before production use.

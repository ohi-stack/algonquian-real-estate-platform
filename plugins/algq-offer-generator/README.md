# Algonquian Offer Generator

Version: 1.0.0
Author: Onegodian | Algonquian Real Estate

## Purpose

Generates acquisition offers and transaction documents from deal data for Algonquian Real Estate workflows.

## Shortcodes

- `[algq_offer_generator]`
- `[algq_offer_builder]`
- `[algq_offer_history]`

## Generated Pages

- `/offer-generator`
- `/generate-offer`
- `/offer-history`

## Supported Offer Types

- Cash Offer
- Seller Financing Offer
- Subject-To Proposal
- Letter of Intent

## Integrations

- Deal Intake
- Pipeline CRM
- MAO Engine
- Document Library
- PDF & Signature Engine
- Automation Engine
- Command Center

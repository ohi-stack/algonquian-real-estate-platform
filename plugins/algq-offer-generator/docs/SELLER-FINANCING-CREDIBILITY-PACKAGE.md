# Seller Financing Credibility Package Mapping

This guide maps the seller-facing proposal workflow into the existing Algonquian platform without making Offer Generator the owner of underwriting, legal instruments, or financing ledgers.

| Package component | Authoritative system |
|---|---|
| ARE company profile / entity records | Document Library |
| Signing-authority resolution | Document Library |
| Property underwriting summary | MAO Engine |
| Seller-financing proposal / term sheet / LOI | Offer Generator |
| Sources and uses | MAO Engine / Funding Tracker as applicable |
| Property operating projection | MAO Engine |
| DSCR analysis | MAO Engine |
| Insurance requirements | Document Library / closing workflow |
| Tax and insurance escrow arrangement | Final transaction documents / servicing workflow |
| Third-party servicing proposal | Document Library |
| Promissory note and mortgage structure | Transaction-specific qualified counsel / closing professional |
| Closing package | Document Library / PDF & Signature / closing professional |

Offer Generator should link the applicable package records by deal and document identifiers rather than copying authoritative records into duplicate data stores.

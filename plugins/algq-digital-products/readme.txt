Authoritative digital-product catalog, metadata, presentation, and WooCommerce product-linking module for the Algonquian Real Estate platform.

== Description ==

Algonquian Digital Products manages digital-product records, categories, visibility, versions, delivery classifications, public catalog presentation, and optional WooCommerce links.

== Shortcodes ==

[algq_digital_products]
[algq_digital_product id="123"]

== Installation ==

1. Upload the plugin directory or ZIP package.
2. Activate the plugin.
3. Open Digital Products in WordPress administration.
4. Create product records and link WooCommerce products where applicable.
5. Publish the catalog with [algq_digital_products].

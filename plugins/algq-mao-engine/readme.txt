Versioned real estate acquisition underwriting with strategy-specific formulas, sensitivity analysis, approvals, and Algonquian platform integration.

== Description ==

The Algonquian MAO Engine owns underwriting scenarios for the Algonquian Real Estate Platform. Pipeline CRM remains authoritative for deal records. The plugin supports Wholesale, Fix and Flip, Rental, and Multifamily analysis, saves versioned input and result snapshots, and exposes only approved scenarios to offer workflows.

== Installation ==

1. Upload the plugin directory or release ZIP.
2. Activate the plugin.
3. Review MAO Engine > Settings.
4. Assign granular capabilities through the Platform Plugin.
5. Validate the generated calculator page.

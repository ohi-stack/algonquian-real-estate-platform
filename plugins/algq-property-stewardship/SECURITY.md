# Security Policy

Stewardship client, visit, and vendor records are private operational records. They must not be exposed through public REST routes, unscoped shortcodes, public attachment URLs, or broad logged-in-user queries.

Portal access is record-scoped to the current WordPress user. Protected visit documents are delegated to the platform/Document Library secure-delivery layer through `algq_secure_document_url`.

Report security issues privately to the site owner or technology administrator. Do not publish client addresses, visit histories, photographs, authorization records, or vendor-access details in public issues.

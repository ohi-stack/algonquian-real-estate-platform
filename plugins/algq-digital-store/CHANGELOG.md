# Changelog

## 1.2.0 — 2026-08-25

### Added

- Fully branded Algonquian Digital Store administrative dashboard.
- ARE Tech navy, gold, teal, and white visual system aligned with the Algonquian Agent Engine administrative interface.
- Live WooCommerce-backed revenue, paid-order, customer, product, and recent-order summaries.
- Branded store-status, digital-delivery, quick-action, and platform-health panels.
- Dedicated responsive admin stylesheet loaded only on the Digital Store dashboard.
- Direct operational links to the storefront, products, and orders.

### Changed

- Replaced the generic WordPress status table with an executive commerce workspace.
- Updated plugin identity to Algonquian Real Estate, LLC and version 1.2.0.
- Preserved WooCommerce as catalog/order/download authority and the Platform Plugin as shared Stripe authority.

## 1.1.0 — 2026-07-31

### Added

- WooCommerce-backed product catalog with category and limit controls.
- Authenticated Product Vault using server-side customer downloads and paid orders.
- Idempotent `algq_digital_store_entitlement_granted` events for paid orders.
- Platform audit-event integration point.
- Granular Digital Store and Product Vault capabilities.
- Idempotent canonical page generation for `/store/`, `/product-vault/`, and `/store/checkout/`.
- Shared Algonquian interface styling and responsive states.
- Security policy and conservative uninstall behavior.

### Changed

- Replaced hard-coded sample products with authoritative WooCommerce products and prices.
- Replaced placeholder Product Vault content with actual customer downloads and order history.
- Moved checkout responsibility entirely to WooCommerce and shared platform payment services.
- Updated plugin metadata and documentation for the 1.1.0 hardening release.

### Security

- Paid status is derived only from server-side WooCommerce orders.
- Download URLs are generated by WooCommerce customer-download permissions.
- Payment credentials and card data are not stored by this plugin.
- Entitlement events are emitted once per paid order.

## 1.0.0

- Initial catalog, Product Vault placeholder, checkout shortcode, admin page, and WPBakery page generation.

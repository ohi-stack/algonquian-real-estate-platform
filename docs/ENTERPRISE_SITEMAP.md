## 18. WordPress and WPBakery implementation rules

- Generated pages must be created idempotently.
- Existing administrator-edited pages must not be overwritten.
- Generated page IDs and page-type metadata must be stored.
- Dynamic routes must be implemented through rewrite rules, endpoint handlers, or plugin-controlled application pages rather than creating one WordPress page per record.
- Public pages should be indexable only when intended.
- Protected pages must enforce capabilities at the destination.
- WPBakery content must use `[vc_column_text] ... [/vc_column_text]` and never HTML-style closing tags.

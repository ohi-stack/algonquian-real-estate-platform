# Algonquian Real Estate Mega Menu

## Navigation objective

The primary website navigation should organize Algonquian Real Estate around the visitor's situation and intended action rather than exposing the internal plugin architecture as the main public navigation.

The mega menu should use six top-level sections:

1. Property Owners
2. Buy & Invest
3. Property Services
4. Development
5. ARE Platform
6. About

A persistent primary call to action should read **Discuss Your Property** and link to `/contact/` or the approved homeowner consultation intake page.

# Header utility navigation

Above or beside the main navigation, provide compact utility links:

- Buyer Login
- Client Portal
- Tenant Portal
- Documents
- Contact

Do not expose internal administrative pages, deal records, underwriting records, automation rules, lender records, or command-center routes to unauthenticated visitors.

# Mobile behavior

- Convert every top-level mega-menu section into an accordion.
- Keep the primary CTA visible near the top of the mobile menu.
- Use section headings and short descriptions, not an undifferentiated link list.
- Ensure keyboard operation, focus states, screen-reader labels, and escape-to-close behavior.
- Do not rely on hover as the only interaction.

# Visual standard

- Dark navy menu background.
- White headings and body text.
- Gold section accents.
- Teal active and focus indicators.
- Four-column desktop layout where appropriate.
- Featured cards with restrained imagery and one clear CTA.
- Consistent iconography and spacing from the shared platform design system.

# WordPress implementation requirements

The Platform Plugin should own the menu registration and renderer.

Recommended menu locations:

```php
register_nav_menus(
    array(
        'algq_primary' => __( 'Algonquian Primary Navigation', 'algonquian-real-estate-platform' ),
        'algq_utility' => __( 'Algonquian Utility Navigation', 'algonquian-real-estate-platform' ),
        'algq_footer'  => __( 'Algonquian Footer Navigation', 'algonquian-real-estate-platform' ),
    )
);
```

Recommended shared classes:

```text
ALGQ_Mega_Menu
ALGQ_Mega_Menu_Walker
ALGQ_Menu_Access_Control
ALGQ_Menu_Page_Resolver
ALGQ_Menu_Cache
```

The renderer should support:

- column headings
- descriptions
- featured cards
- icons
- CTA buttons
- role- and capability-aware visibility
- active trail states
- mobile accordion states
- menu caching with invalidation after menu edits
- graceful fallback to ordinary WordPress navigation

# Editorial rule

Public navigation should lead with homeowner needs and opportunities. The internal plugin names should remain grouped under **ARE Platform**, not dominate the main customer-facing navigation.

The homeowner-oriented structure reflects ARE's positioning as a company that helps Connecticut property owners find the right path forward, including legacy planning, stewardship, inherited-property guidance, transition assistance, and seller options. The plugin catalog and application routes remain available as a dedicated platform section.
